# Extension declarations

[API reference](../apiref.md) | [Implementation guide](../implementing/required.md)

`H2Factory.Interfaces` contains generic declarations only.
For any declared hook, `H2Factory.<name>` and `H2Factory.Interfaces.<name>` refer to the
same function.
The [implementation guide](../implementing/required.md) lists required methods and defaults.

```@autodocs
Modules = [H2Factory.Interfaces]
```
