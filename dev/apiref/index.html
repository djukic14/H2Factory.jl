Coupling storage trait

i2otrait

H2Factory.i2otrait(collection) returns the trait that selects the coupling kernel. Built-in choices include H2Factory.DenseTranslation(), H2Factory.DiagonalTranslation(), and H2Factory.ToeplitzI2OTranslationTrait(). A wrapper must declare or forward its trait; the trait describes the stored operator, not the map's forward/transpose/adjoint orientation.

i2otranslator

H2Factory.i2otranslator(core, trait) exposes the core's I2O translation to a workspace. Normally it returns an H2Factory.I2OTranslation combining a coupling collection and modulation policy. The one-argument map accessor resolves its orientation and forwards to the core through the workspace.

Level-transfer application

applytransfer!

H2Factory.applytransfer!(out, in, transfer, direction, accumulation, context) applies an already resolved level transfer. The generic implementation selects the requested direction, then calls H2Factory.applydirectedtransfer!. Dense matrices and SeparableTransfer have built-in implementations. A custom representation must honor both overwrite and accumulation semantics. This is separate from I2O coupling application.

Pool sizing internals

calculatememoryrequirements

H2Factory.calculatememoryrequirements is the internal sizing step used by allocatemomentbuffers. It accounts for moment sizes and alignment while walking the aggregation plans. Its returned groups depend on the plan type. For method construction, use H2Factory.storagemomentsplan rather than calling this internal step or deriving pool lengths by adding node-entry counts.

Leaf-multiply scheduling key

H2Factory.LeafMulOp() identifies leaf multiplication in execution scheduling. It is an internal operation tag, not a leaf-multiply implementation. A core can specialize H2Factory.leafmulscheduler to choose the leaf kernel's inner scheduler when constructing a workspace from a bare scheduler.
