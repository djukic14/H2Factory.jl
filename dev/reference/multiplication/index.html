Moment multiplication

API reference | Moments and leaf collections

These are the LinearAlgebra.mul! methods documented by H2Factory, not the full LinearAlgebra reference. The linked collection-to-output operation uses a transpose; conjugated leaf multiplication is selected separately for adjoint maps. See Transpose and adjoint.

LinearAlgebra.mul! — Method
LinearAlgebra.mul!(resultmoment::AbstractMoment, matrix::AbstractMatrix, moment::AbstractMoment, α, β)

For each flattened component, compute resultmoment[i] = α * matrix * moment[i] + β * resultmoment[i]. Return resultmoment.

source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(resultmoment::AbstractMoment, matrix::AbstractMatrix, moment::AbstractMoment)

Apply matrix to each flattened component of moment, writing into resultmoment. Return resultmoment.

m = H2Factory.Moment{2,Float64}((10, 10))
matrix = rand(100, 100)
resultmoment = typeof(m)(m)
LinearAlgebra.mul!(resultmoment, matrix, m)

LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::H2Factory.ToeplitzMoment{D,T1}, momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * y, for i in 1:D

Arguments

  • moment::H2Factory.ToeplitzMoment{D,T1}: A moment.
  • momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = H2Factory.ToeplitzMoment{2,Float64}((10,))
mcol = H2Factory.ToeplitzMomentCollection{2,Float64}((10, 10))
y = zeros(Float64, 10)

LinearAlgebra.mul!(m, mcol, y)

Returns

  • moment::H2Factory.ToeplitzMoment{D,T1}: The updated moment after multiplication.
source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::H2Factory.ToeplitzMoment{D,T1}, momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::H2Factory.ToeplitzMoment{D,T1}: A moment.
  • momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = H2Factory.ToeplitzMoment{2,Float64}((3, 3))
mcol = H2Factory.ToeplitzMomentCollection{2,Float64}((9, 9))
y = ones(Float64, 9)

LinearAlgebra.mul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::H2Factory.ToeplitzMoment{D,T1}: The updated moment.
source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(result::AbstractArray{<:Number}, momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}, moment::H2Factory.ToeplitzMoment{D,T1})

Transpose operation to LinearAlgebra.mul!(moment, momentcollection, result). If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

result .= 0
result += transpose(momentcollection[i]) * moment[i], for i in 1:D

Arguments

  • result::AbstractArray{<:Number}: An abstract array of numbers.
  • moment::H2Factory.ToeplitzMoment{D,T1}: A moment.
  • momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}: A momentcollection.

Example

m = H2Factory.ToeplitzMoment{2,ComplexF64}((10,))
mcol = H2Factory.ToeplitzMomentCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

LinearAlgebra.mul!(y, mcol, m)

Returns

  • result::AbstractArray{<:Number}: Updated array after the multiplication.
source
