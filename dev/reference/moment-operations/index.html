Conjugated and diagonal multiplication

API reference | Translation guide

conjmul! handles conjugated moment-collection multiplication for linked pairs. elementwisemul! applies diagonal couplings. Ordinary matrix multiplication has its own reference page.

H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::H2Factory.ToeplitzMoment{D,T1}, momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * conj(y), for i in 1:D

Arguments

  • moment::H2Factory.ToeplitzMoment{D,T1}: A moment.
  • momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = H2Factory.ToeplitzMoment{2,ComplexF64}((10,))
mcol = H2Factory.ToeplitzMomentCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

H2Factory.conjmul!(m, mcol, y)

Returns

  • moment::H2Factory.ToeplitzMoment{D,T1}: The updated moment after conjugate multiplication.
source
H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::H2Factory.ToeplitzMoment{D,T1}, momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::H2Factory.ToeplitzMoment{D,T1}: A moment.
  • momentcollection::H2Factory.ToeplitzMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = H2Factory.ToeplitzMoment{2,ComplexF64}((3, 3))
mcol = H2Factory.ToeplitzMomentCollection{2,ComplexF64}((9, 9))
y = Array(1:9) * im

H2Factory.conjmul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::H2Factory.ToeplitzMoment{D,T1}: The updated moment after conjugate multiplication.
