Type-generation macros

API reference | Moments and leaf collections

The moment macros define concrete storage types and their linked operations. The operator-wrapper macros require their optional integration to be loaded; see Assembly and extensions.

H2Factory.@createlinked — Macro
@createlinked MomentName CollectionName [AbstractMomentType AbstractCollectionType]

Create a moment type and a matching collection type, then link their multiplication methods. Without parent types, the new types subtype H2Factory.AbstractMoment and H2Factory.AbstractMomentCollection.

source
H2Factory.@createlinkedtoeplitz — Macro
@createlinkedtoeplitz MomentName CollectionName [AbstractMomentType AbstractCollectionType]

Create a Toeplitz moment type and a matching collection type, then link their multiplication methods. Without parent types, the new types use H2Factory's abstract moment types.

source
H2Factory.@createmoment — Macro

@createmoment StructName AbstractType

Define a moment type with D component arrays of the same size. It subtypes AbstractType{D,T}, where T is the component array type.

Example

abstract type NewAbstractMoment{D,T} <: H2Factory.AbstractMoment{D,T} end
@createmoment MyMoment NewAbstractMoment
@show m = MyMoment{2,Float64}((10,))
@show m = MyMoment(m.moments)
@show m = MyMoment(m)
source
H2Factory.@createmoment — Macro

@createmoment StructName

Similar to @createmoment StructName AbstractType, but the abstract type is implied to be H2Factory.AbstractMoment.

Example

@createmoment MyMoment
@show m = MyMoment{4,Float64}((3, 3, 3))
@show m = MyMoment(m.moments)
@show m = MyMoment(m)

@show H2Factory.dim(m)

# iterator over each array of the moment
for i in eachindex(m)
    # access each array of the moment
    println(m[i])
end
source
H2Factory.@createmomentcollection — Macro

@createmomentcollection StructName AbstractType

Define a collection type with D moment matrices of the same size. It subtypes AbstractType{D,T}, where T is the matrix type.

Example

abstract type NewAbstractMomentCollection{D,T} <: H2Factory.AbstractMomentCollection{D,T} end
@createmomentcollection MyMomentCollection NewAbstractMomentCollection
@show m = MyMomentCollection{2,Float64}((10, 10))
@show m = MyMomentCollection(m.moments)
@show m = MyMomentCollection(m)

# not allowed since arrays in collection are supposed to be abstract matrices
@show m = MyMomentCollection{2,Float64}((10,))
source

H2Factory.@traitaccessor — Macro
@traitaccessor name forwardbody flipbody

Define the usual three methods for an accessor:

name(A)                                 = name(forwardmap(A), maptrait(A))
name(A, ::isForward)                    = forwardbody
name(A, ::Union{isTranspose,isAdjoint}) = flipbody

forwardbody and flipbody use A and can name fields or other accessors. Use this macro for accessors whose transpose and adjoint forms both swap test and trial sides.
