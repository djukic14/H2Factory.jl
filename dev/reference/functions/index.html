# Indexing returns the array itself. Use identity because fresh storage is uninitialized.

for i in eachindex(m)

end

H2Factory.Interfaces.i2ochannels — Method
i2ochannels(translation, translatingplan)

Build fresh I2O scratch channels for a workspace. Borrow buffers with borrowbuffer(channel, level, chunkid, maptrait).

An I2OTranslation delegates to its coupling collection. Collections needing no scratch return EmptyChannels; others provide their own method for buffers or FFT plans. Each workspace must have its own scratch.

Call inside withschedulechunks, since buffer counts use nchunks(level).

H2Factory.Interfaces.modulate_in! — Method
modulate_in!(moment, level, maptrait, modulation, coupling, channel, scheduler, buffer)

Convert moment into the coupling basis in place, before applying the node's I2O couplings. Policies may use coupling, channel, and the borrowed buffer for plans or scratch. NoModulation leaves it unchanged. A Toeplitz moment paired with NoModulation rejects instead (see below) – a Toeplitz moment always needs converting into the frequency domain, so skipping that step must never happen silently, through ANY coupling collection.

componentsource(symmetry, i, j) -> (sourcei, sourcej, scale)

Return the canonical component indices and scale for a 3-D vector or tensor transformed by symmetry. For a signed coordinate permutation S:

(S*v)[i] = signs[i] * v[perm[i]]

latticegridpermutation(gridsize, symmetry) -> Vector{Int32}

Return the linear-index permutation of a tensor grid: permutation[i] indexes the image of point i under symmetry.

H2Factory.symmetryreducedcollection — Method
symmetryreducedcollection(canonical, permutationfor)

Wrap each stored coupling in a PermutedTranslation. canonical must carry symmetry tags, usually from H2Trees.SymmetryDirectionInvariancePerLevel.

permutationfor(receivingnode, symmetry) returns the sample-index permutation for that pair. The supplied symmetry maps the canonical direction to the actual direction. For angular samples, the callback uses its inverse: T(k, S*d) == T(inv(S)*k, d).

The coupling and symmetry are read from the same stored key, including for transpose and adjoint. Both nodes are at the same level, so receivingnode identifies the required sample grid.

source
H2Factory.symmetryreduceddensecollection — Method
symmetryreduceddensecollection(canonical, gridsizefor; componentaction=nothing)
symmetryreduceddensecollection(canonical, rowgridsizefor, columngridsizefor; componentaction=nothing)

Share canonical dense couplings through row/column grid permutations. canonical must carry symmetry tags, usually from H2Trees.SymmetryDirectionInvariancePerLevel.

rowgridsizefor(node) and columngridsizefor(node) return interpolation-grid shapes as tuples. Rows belong to the receiving node, columns to the translating node. The two-argument form uses one callback for both sides.

Use componentaction=nothing for scalar couplings, or TrueTensor/PseudoTensor for 3x3 tensor couplings. VectorField is not supported.

The kernel must obey the declared symmetry rule and the grid points must be symmetric about the box centre. Callers verify these properties; under those conditions, reduction adds no approximation.

H2Factory.toeplitzpermutation — Method
toeplitzpermutation(toeplitzsize, symmetry) -> Vector{Int32}

Return the linear-index permutation for a circulant-embedded Toeplitz difference tensor. toeplitzsize is the stored size (2n-1 per axis), not the moment size. Difference d is stored at mod(d, L) + 1 on an axis of length L.

The permutation applies the inverse symmetry to difference indices, so for a symmetry-invariant scalar kernel, kernel(S*d)[j] == kernel(d)[permutation[j]]. It also applies to the FFT of the embedded tensor. Field-component transformations are handled separately.

Axes exchanged by the symmetry must have equal lengths; otherwise this raises an error.
