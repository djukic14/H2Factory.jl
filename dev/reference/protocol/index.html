Extension declarations

API reference | Implementation guide

H2Factory.Interfaces contains generic declarations only. For any declared hook, H2Factory.<name> and H2Factory.Interfaces.<name> refer to the same function. The implementation guide lists required methods and defaults.

H2Factory.Interfaces — Module
H2Factory.Interfaces

Generic declarations for H2Factory's extension protocol; no methods or types. H2Factory imports these bindings, so H2Factory.f and H2Factory.Interfaces.f are the same function. Membership here does not imply export.

H2Factory.Interfaces.aggregateleafchunk! — Function
aggregateleafchunk!(A, tree, chunknodes, moment, momentcollection, leafmul!, x, level, leafbuffer)

Apply aggregation leaf multiplication to chunknodes. The default calls aggregateleaf! per leaf. Specialize on leafbuffer to batch work; momentcollection is an accessor closure. Chunks can also contain internal nodes, so implementations must filter for leaves.

H2Factory.Interfaces.applycouplingkernel! — Function
applycouplingkernel!(out, in, coupling, i2otrait, receivingnode, translatingnode, direction,
                     accumulation, context)

Apply one coupling block after symmetry validation and trait resolution. Collections implement this kernel, usually dispatching on i2otrait. Use H2Factory.couplingkey for the directed key and H2Factory.directedoperation for the matrix orientation.

Extend this kernel, not the guarded H2Factory.applycoupling! entry. Also define assertnosymmetry and i2otrait; do not repeat the guard here.

H2Factory.Interfaces.applyleafmul! — Function
applyleafmul!(leafbuffer, moment, momentcollection, x)
applyleafmul!(leafbuffer, y, momentcollection, moment, α, β)

Multiply a leaf collection with this chunk's private scratch. The default calls LinearAlgebra.mul! and ignores leafbuffer. Specialize for collections needing scratch; buffer and collection always belong to the same side.

source
H2Factory.Interfaces.assemble — Function
assemble(assembler::AbstractNearInteractionsAssembler, values, nearvalues, verbose=false)
assemble(assembler::AbstractNearInteractionsAssembler, selfvalues, values, nearvalues, verbose=false)

Assemble the near block for the interaction groups supplied by the strategy. The five-argument form separates self values; the four-argument form does not. Concrete assemblers implement the forms they use. Missing methods raise MethodError; an intentionally empty assembler must still implement its method.

source
H2Factory.Interfaces.assertnosymmetry — Function
assertnosymmetry(collection)

Refuse a collection whose symmetry tags have not been consumed by the plain translation path.

There is no permissive default. Wrappers should forward to their contained collection; collections that cannot carry unconsumed tags should return nothing.

Return one chunk's private scratch from a channel.

Concurrent chunks must never receive the same mutable buffer. EmptyChannels returns a stand-in for operations that need no scratch.

H2Factory.Interfaces.conjmul! — Function
conjmul!(moment, momentcollection, y)
conjmul!(moment, momentcollection, y, α, β)
conjmul!(y, momentcollection, moment[, α, β])

Multiply with conjugation in place. The moment-output forms conjugate the input vector; the vector-output forms conjugate the transposed product. See each method for its formula.

@linkmomenttocollection generates methods for linked pairs only. Other pairs raise MethodError. Use concrete moment and collection types when querying hasmethod.

H2Factory.Interfaces.coupling — Function
coupling(translation)

Return the coupling of an I2OTranslation. Bare AbstractI2OCouplingCollections return themselves. Wrappers must expose their collection or use I2OTranslation(coupling, modulation).

source
H2Factory.Interfaces.i2ochannels — Function
i2ochannels(translation, translatingplan)

Allocate per-(level, chunk) I2O scratch for a coupling or modulation policy.

Each workspace must own its mutable plans and scratch. I2OTranslation delegates to its coupling, and collections needing no scratch return EmptyChannels. Call this inside withschedulechunks when sizing depends on nchunks(level).

source
H2Factory.Interfaces.isgalerkinsymmetric — Function
isgalerkinsymmetric(operator) -> Bool

Return whether a Galerkin near block is symmetric, allowing one triangle to be mirrored. The value form calls isgalerkinsymmetric(typeof(operator)). Defaults to false: a false symmetry claim would omit required assembly.

source
H2Factory.Interfaces.leafmul — Function
leafmul(A) -> functor

Return the leaf multiplication functor for A. Specialize on (core, maptrait); the map form resolves these through forwardmap and maptrait. Forward and transpose have defaults. Adjoint must opt in: use the plain functor only when both leaf collections are real; otherwise provide conjugation.

source
H2Factory.Interfaces.leafmulscheduler — Function
leafmulscheduler(core) -> scheduler

Return the scheduler for H2Factory.LeafMulOp when constructing execution scheduling from a bare scheduler. The default is SerialScheduler(). A prebuilt ExecutionScheduling is preserved.

H2Factory.Interfaces.modulate_in! — Function
modulate_in!(moment, level, maptrait, modulation, coupling, channel, scheduler, buffer)

Convert a node's aggregation moment into the coupling basis, in place, before the I2O phase.

This runs once per node rather than once per interaction. Implementations may use the coupling, channel, and borrowed buffer for plans or scratch.

source
H2Factory.Interfaces.modulate_out! — Function
modulate_out!(moment, level, maptrait, modulation, coupling, channel, scheduler, buffer)

Convert a node's moment back from the coupling basis after I2O. This is the output stage paired with modulate_in!.
