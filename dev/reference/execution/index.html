Workspaces and scheduling

API reference | Scratch and scheduling

H2Workspace builds an executable map; similarworkspace allocates another workspace over the same core. ExecutionScheduling selects per-phase and per-level settings. Low-level helpers are included below for reference.

H2Factory.H2Workspace — Method
H2Workspace(core, scheduling) -> GalerkinH2Workspace | PetrovGalerkinH2Workspace

Allocate an executable workspace over the read-only core. Each call creates fresh moments, buffers, and scratch channels. Workspaces may share a core, but a workspace cannot run two operations at once.

Pass an ExecutionScheduling or a bare scheduler. For a bare scheduler, nchunks can override the number of scratch chunks. A prebuilt ExecutionScheduling already sets that count, so it cannot be combined with nchunks.

H2Factory.Interfaces.borrowbuffer — Method
borrowbuffer(store::BufferStore, chunkid)
borrowbuffer(channels, level, chunkid, trait)

Return the scratch buffer for a chunk. The level-indexed form returns EmptyChannels when channels has no entry for level.

H2Factory.acquireworkspace! — Method
acquireworkspace!(A)

Take exclusive ownership of the workspace behind A, or throw if it is already in use. Transpose and adjoint views share the same flag. This is a no-op for maps without a workspace. Pair it with releaseworkspace! in a finally block.

source
H2Factory.buildleafchannels — Method
buildleafchannels(core)

Build leaf-multiply scratch for this workspace. The default EmptyChannels needs no scratch. A core that needs it may return one channel or a SidedChannels pair. Size per-level pools with nchunks(level).

source
H2Factory.busyflag — Method
busyflag(A)

The ownership flag of the workspace behind A, or nothing if A is not workspace-backed.

source
H2Factory.checkexecutiondata — Method
checkexecutiondata(A)

Warn once if the schedule's requested chunk count is below the outer scheduler's worker count. The comparison uses the map's own scheduler at the first aggregation level. Fewer chunks can leave workers idle; it does not make buffer indexing unsafe. A smaller count may also be intentional to save memory.

source
H2Factory.core — Method
core(A)

Return the shared AbstractH2Core used by a workspace or map.

transpose(A) and adjoint(A) use the same core as A. Passing a core returns that core.

source
H2Factory.createchannel — Method
createchannel(buffers) -> BufferStore

Collect buffers into a chunk-indexed store. Provide a separate mutable buffer for each chunk; this function does not copy the buffers themselves.

source
H2Factory.defaultexecutionscheduling — Method
defaultexecutionscheduling(levels; outer=DynamicScheduler(), nchunks=Threads.nthreads(),
                           leafmul=SerialScheduler())

Use outer for every traversal plan, serial inner kernels, and one chunk per Julia thread.

leafmul overrides the inner scheduler for batched leaf work.

source
H2Factory.maxnchunks — Method
maxnchunks(levels::Int...)

Return the largest scheduled chunk count among levels, skipping missing levels.

Use this when a shared buffer pool serves traversals that borrow it using chunk IDs from different levels. Throws an error if none of the levels has a schedule.

source
H2Factory.momentbuffers — Method
momentbuffers(A)

Return the memory pools backing the test and trial moments. They must stay alive while the moments use them. The same pools serve every map direction.

Map types with different storage should override momentbuffers(A, trait). Workspaces keep their own pools in WorkspaceBuffers.

source
H2Factory.nchunks — Method
nchunks(scheduling::ExecutionScheduling)

Return the node-partition granularity and corresponding buffer-pool size.

source
H2Factory.nchunks — Method
nchunks(level::Int)

Return the number of chunks at level in the current schedule. Use inside withschedulechunks. A missing level raises KeyError.

source
H2Factory.nchunks — Method
nchunks()

Always throws an error. Chunk counts vary by level; use nchunks(level) inside withschedulechunks.

source
H2Factory.outerscheduling — Method
outerscheduling(default, levels)
outerscheduling(default, levels, (op, level) => scheduler, ...)

Build an OuterScheduling with default at every plan and level, then apply sparse (plan, level) => scheduler overrides:

outerscheduling(DynamicScheduler(), levels,
                (I2OOp(), 3) => DynamicScheduler(; ntasks=8),
                (TestDisaggregationOp(), 5) => SerialScheduler())

Overrides are stored directly in the per-level containers.

source
H2Factory.perlevel — Method
perlevel(scheduler, levels)

Map each tree level in levels to scheduler.

A typed Dict supports noncontiguous level ranges while preserving type-stable lookup.

source
H2Factory.plans — Method
plans(core)

Return the core's plans. H2Workspace uses them to build its own Schedules. By default, this reads core.plans.

source
H2Factory.releaseworkspace! — Method
releaseworkspace!(A)

Release ownership taken by acquireworkspace!. Idempotent, and a no-op for a non-workspace.

source
H2Factory.requestedntasks — Method
requestedntasks(scheduler)

Return the scheduler's requested task count, used as its natural chunk and scratch-pool count.

SerialScheduler returns one. Schedulers without a fixed or discoverable count fall back to Threads.nthreads().

source
H2Factory.schedulechunkcounts — Method
schedulechunkcounts(schedule::PlanSchedule) -> Dict{Int,Int}
schedulechunkcounts(schedules::Schedules) -> Dict{Int,Int}

Return the actual number of chunks needed at each level for scratch buffers.

For one plan, use the larger count from node chunks and receiving chunks. For a Schedules bundle, use the largest count across its four plans at each level. This covers every map direction.

source
H2Factory.scheduledop — Method
scheduledop(op, maptrait) -> AbstractH2Operation

Return the inner-scheduler key for this map orientation. Forward preserves the key. Transpose/adjoint swap I2IOp and O2OOp, keeping each scheduler with its tree:

innerscheduler(A, O2OOp(), level) == innerscheduler(transpose(A), I2IOp(), level)

Other keys stay unchanged. This changes scheduler lookup, not the kernel executed. Outer phases select their plans separately.

H2Factory.schedules — Method
schedules(A)

Return the workspace's materialized Schedules.

source
H2Factory.scheduling — Method
scheduling(A)

Return the workspace's ExecutionScheduling.

H2Factory.serialexecutionscheduling — Method
serialexecutionscheduling(levels; nchunks=1)

Use serial outer and inner scheduling. The default is one chunk.

source
H2Factory.serialinnerscheduling — Method
serialinnerscheduling(levels; leafmul=SerialScheduler())

Use serial scheduling for every local kernel at every level. leafmul may be overridden separately for implementations that batch leaf work.

source
H2Factory.similarworkspace — Method
similarworkspace(ws::AbstractH2Workspace; scheduling=scheduling(ws), nchunks=nothing)

Allocate fresh mutable buffers over core(ws). Reuse the execution scheduling by default, or pass scheduling to change it. The nchunks restriction is the same as for H2Workspace.

source
H2Factory.withnchunks — Method
withnchunks(f, counts::AbstractDict{Int,Int})

Run f() with counts available to nchunks(level). Prefer withschedulechunks, which gets the counts from Schedules.

source
H2Factory.withschedulechunks — Method
withschedulechunks(f, schedules::Schedules)

Run f() with the actual per-level chunk counts available to nchunks(level). Build buffer pools inside this scope so they match the traversal's chunks.

source
H2Factory.withworkspace — Method
withworkspace(f, A)

Run f() while owning the workspace behind A. Release it even if f throws.

source
H2Factory.workspacebuffers — Method
workspacebuffers(A)

Return the WorkspaceBuffers behind A. Forward, transpose, and adjoint views share them.
