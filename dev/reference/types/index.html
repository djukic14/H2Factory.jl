API reference | Implementation guide

These definitions describe the data passed between construction, workspaces, and numerical kernels. For the ownership rules, read Moments and leaf collections.

H2Factory.AbstractH2Core — Type
AbstractH2Core{T}

Base type for the shared, read-only data of an H2 map. T is the element type.

Core types provide read-only accessors that take (core, maptrait). They also provide the methods needed to build a workspace: schedulinglevels, plans, buildmoments, buildvectorbuffers, buildi2ichannels, buildo2ochannels, and buildi2ochannel.

Make a subtype of GalerkinH2Core or PetrovGalerkinH2Core. To multiply with a core, first build an H2Workspace from it.

H2Factory.AbstractI2OCouplingCollection — Type
AbstractI2OCouplingCollection

A collection of I2O couplings keyed by node pair. Basis conversion belongs to AbstractI2OModulation.

Concrete collections implement:

  • assertnosymmetry: reject unhandled symmetry tags, forward to a wrapped collection, or return nothing if no tags can remain.
  • i2otrait: select the coupling-storage trait.
  • applycouplingkernel!: apply a pair's coupling for each supported direction and accumulation mode.

Do not specialize applycoupling!: it checks symmetry before calling the kernel. An undeclared assertnosymmetry method raises an error on first use.

H2Factory.ConjugateTranslation — Type

Apply conj(T) without transposing it.

This direction is used by adjoint aggregation. For A = α · (I2I_test · L_test)^T · T_i2o · (I2I_trial · L_trial), the adjoint is

A^H = conj(α) · (conj(I2I_trial) · conj(L_trial))^T · T_i2o^H · conj(I2I_test) · conj(L_test)

so aggregation remains child-to-parent while conjugating the transfer. For real transfers this is equivalent to ForwardTranslation.

H2Factory.Moment — Type
struct H2Factory.Moment{D,T} <: AbstractMoment{D,T}

The H2Factory.Moment struct represents a moment consisting of D arrays of type T. This struct was created with the @createmoment macro of H2Factory.jl.

Fields

  • moments::SVector{D,T}: D arrays of type T.

Constructors

  • H2Factory.Moment{D,T}(size::NTuple{N,I}) where {D,T,I,N}: Creates a new moment with D arrays of type T and size size.
  • H2Factory.Moment{D,T}(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector.
  • H2Factory.Moment{D}(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector, inferring D from the input.
  • H2Factory.Moment(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector, inferring T and D from the input.
  • H2Factory.Moment{D,T}(m::H2Factory.Moment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m. The fields of m are not copied.
  • H2Factory.Moment{D}(m::H2Factory.Moment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m, inferring T from the input. The fields of m are not copied.
  • H2Factory.Moment(m::H2Factory.Moment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m, inferring T and D from the input.

Example

m = H2Factory.Moment{2,Float64}((3, 3))

# access the first array of the moment
m[1] == m.moments[1]

# create a new moment of the same type as `m` without copying the fields of `m`
m2 = H2Factory.Moment(m)

typeof(m2) == typeof(m)

H2Factory.OuterScheduling — Type
OuterScheduling(trialaggregation, testaggregation, i2o, testdisaggregation, trialdisaggregation)

Outer scheduler per traversal plan, stored as per-level containers. Read with outerscheduler(outer, op, maptrait, level).

Keyed by the concrete plan (= node set) each chunk loop walks, not by the phase, because the four (phase, orientation) combinations are four distinct node sets:

phaseforwardtranspose / adjoint
AggregateOptrialaggregationtestaggregation
DisaggregateOptestdisaggregationtrialdisaggregation

i2o has no orientation partner and serves both directions. Each field may cover a different level range, allowing the two sides of a block tree to differ.
