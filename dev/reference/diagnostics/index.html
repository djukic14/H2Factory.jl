H2Factory.Diagnostics — Module
H2Factory.Diagnostics

Inspect H2 maps without changing them, or collect multiplication timings.

Start with h2summary and sanitycheck.

translation_counts reports coupling reuse. profilemul and the timed*! functions collect timings using the normal multiplication path.

source
H2Factory.Diagnostics.DiagnosticIssue — Type
DiagnosticIssue(severity, code, message)

One finding from a structural check. severity is :error, :warning, or :info; code identifies the condition and message describes it.

source
H2Factory.Diagnostics.H2Summary — Type
H2Summary

Map size, tree shape, leaf occupancy, and far-pair counts.

source
H2Factory.Diagnostics.SanityReport — Type
SanityReport(target, issues)

Result of checking target. An empty report is clean. haserrors returns true when any issue has severity :error.

source
H2Factory.Diagnostics.TimingDiagnostics — Type
TimingDiagnostics(; bylevel=true, bynode=false)

Collect TimingRecords. Set bylevel=false to keep only whole-operation records. bynode is reserved for future per-node timing.

source
H2Factory.Diagnostics.TimingRecord — Type
TimingRecord

One timed operation. operation names the work, phase its scope, and mode the map orientation. level and node are missing when they do not apply. Allocation data is only reliable for whole-operation records.

source
H2Factory.Diagnostics.TimingReport — Type
TimingReport(y, records, metadata)

Result of a profiled multiplication. Contains the result y, timing records, and map metadata.

source
H2Factory.Diagnostics.TranslationCounts — Type
TranslationCounts

Counts far pairs and distinct translation operators. reuse is farpairs / uniquetranslations; higher values mean more reuse.

source
H2Factory.Diagnostics.admissibilityreport — Method
admissibilityreport(A::AbstractH2Maps; kwargs...)

Check the translation scheme with H2Trees.checkadmissibility. Forward keywords, defaulting isnear to the map's predicate. Use the forward map: transpose/adjoint share its geometry. This may visit every far pair; run it outside multiplication.

source
H2Factory.Diagnostics.checkmoments — Method
checkmoments(A) -> SanityReport

Check that each far-pair node has a moment and that moments on the same level have the same size.

source
H2Factory.Diagnostics.checkplans — Method
checkplans(A) -> SanityReport

Check the far pairs and, for keyed translation collections, verify that every pair resolves.

source
H2Factory.Diagnostics.diagnostic_rows — Method
diagnostic_rows(report_or_records) -> Vector{NamedTuple}

Convert a TimingReport or vector of records to NamedTuple rows. Each row contains the record fields and a derived milliseconds value.

source
H2Factory.Diagnostics.h2summary — Method
h2summary(A) -> H2Summary

Return a structural summary of A. For a Petrov-Galerkin map, tree fields describe the test tree.

source
H2Factory.Diagnostics.haserrors — Method
haserrors(report::SanityReport) -> Bool

Return true when report contains an error.

source
H2Factory.Diagnostics.profilemul — Method
profilemul(A, x; bylevel=true, bynode=false) -> TimingReport

Profile A * x and return its result with the collected timings. Set bylevel=false to omit per-level records. bynode is reserved for future use.

source
H2Factory.Diagnostics.sanitycheck — Method
sanitycheck(A) -> Vector{SanityReport}

Run checkplans, checkmoments, and checkmomentaliasing. A check that cannot run becomes a warning rather than an exception.

source
H2Factory.Diagnostics.timedfarmul! — Method
timedfarmul!(y, A, x; diagnostics=TimingDiagnostics()) -> y

Run only the far-field pass and overwrite y with its result. Records the total and, when enabled, each far-field level.

source
H2Factory.Diagnostics.timedmul! — Method
timedmul!(y, A, x; diagnostics=TimingDiagnostics()) -> y

Multiply A * x into y and collect timing records. The result is the same as for mul!.

source
H2Factory.Diagnostics.timednearmul! — Method
timednearmul!(y, A, x; diagnostics=TimingDiagnostics()) -> y

Near-field pass only, timed as :near/:total.

source
H2Factory.Diagnostics.totalseconds — Method
totalseconds(report_or_records, operation) -> Float64

Summed seconds of every record with the given operation (e.g. :far).

source
H2Factory.Diagnostics.translation_counts — Method
translation_counts(A) -> TranslationCounts

Count far pairs, distinct translation operators by identity, and their reuse.
